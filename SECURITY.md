# Security Policy

## Supported Versions

Security fixes land on the latest release of FuseScope. We recommend always running the most recent version.

## Reporting a Vulnerability

**Do not report vulnerabilities using public GitHub issues, discussions, or pull requests.**

Report it privately through GitHub's private vulnerability reporting:

1. Go to the [**Security** tab](https://github.com/fuseone-io/fusescope/security) of this repository.
2. Click **Report a vulnerability**, or use [this link](https://github.com/fuseone-io/fusescope/security/advisories/new).
3. Describe the issue with as much detail as you can — affected version, impact, and steps to reproduce. Please submit one report per vulnerability.

This opens a private advisory visible only to you and the FuseScope maintainers. We'll respond there, keep you updated as we work on a fix, and coordinate disclosure.

If the issue also affects upstream SigNoz code, we will coordinate with the SigNoz maintainers as well.
